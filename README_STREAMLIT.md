# Онлайн Streamlit AI режимі

Бұрынғы веб-қосымшаның үстіне архив ішін шығарыңыз. catalog.xlsx және images архивте жоқ, өз каталогыңызды сақтаңыз. Ескі кодтың сақтық көшірмесін жасаңыз.

GitHub-қа app.py, core.py, room_engine.py, requirements.txt және pages/1_Room_design.py жүктеңіз. Streamlit негізгі кіру файлы app.py күйінде қалады. SQLite мен .venv жүктелмейді.

1. https://console.groq.com/keys ішінде аккаунтқа кіріп, API кілтін жасаңыз. Free plan қолданыңыз, ақылы жоспарға ауыспаңыз.
2. Streamlit қосымша баптауларындағы Secrets өрісіне:

```toml
GROQ_API_KEY = "өз-кілтініз"
GROQ_MODEL = "openai/gpt-oss-20b"
```

3. Сақтап, қосымшаны жаңартыңыз. Room design бетін ашып, «AI · бұлт (Groq)» таңдаңыз.

Әдепкі GPT-OSS-20B модель ID-сы ресми Groq production тізімінен алынды. Бұл модель Qwen емес; жергілікті Qwen режимі бөлек сақталған. Қазіргі модель тізімінде Qwen preview нұсқасы qwen/qwen3.8-27b бар; оны GROQ_MODEL арқылы таңдауға болады, бірақ preview өзгеруі/өшірілуі мүмкін. Қазіргі қолжетімді ID-ларды аккаунтта тексеріңіз.

API тегін лимит шегінде ғана. Лимит аккаунт пен модельге байланысты. 429 қатесінде сайт себепті көрсетіп тоқтайды; ақылы жоспарға автоматты ауыспайды. Код 3 түзету әрекетін қолдануы мүмкін, олар бөлек сұраулар болып есептеледі. API-ге бөлме параметрлері, каталогтағы таңдалған жиһаз ID/категория/өлшемдер жіберіледі; кілт сервердегі Secrets ішінде болады.

Сұрау мысалы: «Мне нужен дизайн спальни 4 на 4 метра, белая мебель, бюджет примерно 500К». Параметрлерді сұраудан алып, қолмен тексеріңіз. Төсек табылмаса «Бар жиһазбен жоспар жасау» режимі оны өткізіп жібереді, «Үлгілік жиһазбен толықтыру» шаблон төсек қояды. Үлгілік объект бағасы белгісіз; толық жиынтықтың бюджетке сыятыны расталмайды. «Толық жиынтықты талап ету» режимі bed және wardrobe болмаса тоқтайды.

Стиль: minimalist, scandinavian, loft, classic, modern. Белгісіз стиль тауарлары нақты стиль сұралғанда таңдалмайды.

Бюджет, қабаттасу, бұрылу, бөлме шекарасы және алдыңғы бос орын тексеріледі. Есік/терезенің бос аймақтарын қолмен енгізіңіз. Геометриялық ережелер кәсіби интерьер/құрылыс нормаларын алмастырмайды; тұтас өту жолының байланыстылығы және төсектің екі бүйірі әзірге тексерілмейді.

Қосымша мүмкіндіктер мен категориялар README_ROOM.md ішінде. Тесттердің HTTP жауаптары имитацияланған; нақты API-мен генерация сапасы кілт қосылған соң тексеріледі.
