# Бөлме дизайны: сайтқа жаңарту

ZIP ішін бұрынғы webapp папкасына шығарыңыз. app.py, core.py және requirements.txt жаңартылады. catalog.xlsx пен images бұл архивте жоқ: өз деректеріңіз қалады. Әуелі бұрынғы кодты сақтық көшірмеге көшіріңіз.

## Іске қосу

PowerShell, өз webapp папкаңызда:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Сол жақ мәзірден Room design бетін ашыңыз. Сұрауды жазып, «Сұраудан параметрлерді алу» басыңыз; параметрлерді тексеріп, қажет болса түзетіңіз. «Ақ стиль» түс ретінде алынады, интерьер стилі бөлек.

## Тегін жергілікті Qwen

1. https://ollama.com/download/windows сайтынан Ollama орнатыңыз.
2. PowerShell: `ollama pull qwen2.5:3b`.
3. Ollama жұмыс істеп тұрған кезде сайттағы AI режимін таңдаңыз.

Код Ollama localhost:11434 /api/chat endpoint-іне JSON жібереді. Ақылы API қолданылмайды. Модель жүктелуі шамамен 1.9 GB, RAM қажеттілігі одан жоғары; CPU жылдамдығы компьютерге байланысты.

AI модель жиһаздың категориясын, нақты еден өлшемдерін, бөлме шекараларын және бос аймақтарды алады. Каталогтан тауар ID-лары өзгермейді. Python барлық ID толықтығын, қайталануды, координаталар мен бұрылуды, қабаттасуды, шекараны және алдыңғы бос орынды тексереді. Қате ұсынысты түзетуге 3 әрекет беріледі. AI сәтсіз болса алгоритмге үнсіз ауыспайды.

«Алгоритм · AI емес» режимі Qwen-ді қажет етпейді және 20 см торда шектелген іздеу орындайды. Нәтижеде нақты қолданылған әдіс көрсетіледі.

## Каталог

Міндетті бағандар: product_id, name, category, price_kzt, width_cm, depth_cm, available, color. Карточкалар үшін product_url және images/Pxxx.jpg (.jpeg/.png/.webp) қолданылады.

Ұсынылатын бағандар: room_types, style, style_source.

Категория кодтары:
- bedroom: bed, wardrobe міндетті; nightstand, dresser қосымша.
- living_room: sofa міндетті; coffee_table, tv_stand, armchair қосымша.
- office: desk, chair міндетті; bookcase, dresser қосымша.

room_types: bedroom; living_room; office. Бос мән категорияның шаблонына сүйенуге мүмкіндік береді.

style: minimalist; scandinavian; loft; classic; modern. Бір тауарға бірнеше мәнді нүктелі үтірмен жазыңыз. Орысша негізгі атаулар да нормализацияланады. Стильді сұрағанда белгісіз стильдегі тауар өтпейді. Стиль сипаттамаға сүйенсе дереккөзін, сурет бойынша берілсе қолмен бағаланғанын белгілеңіз.

width_cm × depth_cm — жиһаздың толық сыртқы еден өлшемі, матрас өлшемі емес. Қолжетімділік каталог мәніне сүйенеді. Жалпы баға таңдалған барлық тауарлардың қосындысы.

## Есік пен терезе

Төменгі сол жақ бұрыш (0,0), бірлік — сантиметр. Есік ашылатын/өту аймағын кестеге тіктөртбұрышпен енгізіңіз. Белгісіз болса сызба «алдын ала» деп көрсетіледі. Бөлме әзірге тіктөртбұрышты. Сызба жоспарлық қарапайым схема, кәсіби құрылыс сызбасы емес.

Барлық жиһаз алдында бапталатын бос жолақ тексеріледі (әдепкі 60 см). Төсектің екі бүйіріне қолжетімділік, есік механизмінің дәл геометриясы және тұтас жүру жолының байланыстылығы әзірге тексерілмейді.

## Жад және бұлт

Жасырылған тауарлар бұрынғы memory.sqlite файлынан оқылады. Соңғы жоспар session_state ішінде, барлық сәтті жоспар room_memory.sqlite ішінде сақталады. «SQLite-дан қалпына келтіру» сақталған жазбаны көрсетеді; ескі каталогтағы баға/өлшеммен схеманы автоматты шығармайды.

Streamlit Community Cloud-та localhost — бұлт серверінің өзі, сіздің ноутбугыңыз емес. Сондықтан жергілікті Qwen режимі онда Ollama болмаған кезде жұмыс істемейді. Бұлтта алгоритм режимі немесе жергілікті AI-дан экспортталған JSON жүктеу режимін қолданыңыз. JSON ID, бюджет, түс, стиль және геометрия бойынша қайта тексеріледі. Импорттағы «AI» шығу тегі файл авторының мәлімдемесі, ол тәуелсіз тексерілмейді.

SQLite-ды GitHub-қа жүктемеңіз. Бұлттағы қайта орналастырудан кейін SQLite сақталуы кепілденбейді.

## Тексерістер

```powershell
.\.venv\Scripts\python.exe -m unittest test_room_engine -v
```

Тесттер жасанды шағын fixture қолданады; fixture дүкен тауары ретінде каталогқа қосылмайды. Qwen қайталау тестінде HTTP жауаптары имитацияланған. Нақты модельмен генерация сапасы бөлек тексерілуі тиіс.

Каталогтан әр категорияда үздік 8 нұсқа, beam ішінде 120 күй, орналастыруға үздік 12 жиынтық қаралады. Бұл глобалды оптимумды немесе шешімнің жоқтығын дәлелдемейді. Жиынтықтарда қосымша жиһаз саны және E5 ұқсастығы басым, тең жағдайда арзан жиынтық таңдалады.
